Bài 1: Xác định thứ trong tuần

Yêu cầu: Nhập một số nguyên từ 1 đến 7. Dùng switch...case để hiển thị thứ tương ứng.

Hướng dẫn

  1. Khai báo một biến kiểu int.
  2. Nhập giá trị bằng scanf().
  3. Dùng switch để kiểm tra giá trị.
  4. Tạo các case từ 1 đến 7.
  5. Sau mỗi case cần có break.
  6. Dùng default để xử lý dữ liệu không hợp lệ.

Khung chương trình

#include <stdio.h>

int main() {

    int thu;

    printf("Nhap so tu 1 den 7: ");
    scanf("%d", &thu);

    switch(thu) {

        case 1:
            // Tu viet lenh
            break;

        case 2:
            // Tu viet lenh
            break;

        // Bo sung cac case con lai

        default:
            // Xu ly khi nhap sai
            break;
    }

    return 0;
}

Bài 2: Máy tính đơn giản

Yêu cầu: Nhập hai số a, b và một phép tính +, -, *, /. Dùng switch...case để xử lý phép tính.

Hướng dẫn

  1. Khai báo hai biến số thực a và b.
  2. Khai báo biến char để lưu phép tính.
  3. Nhập a, b và phép tính.
  4. Dùng switch với biến phép tính.
  5. Tạo các case '+', '-', '*', '/'.
  6. Riêng phép chia cần kiểm tra b có bằng 0 hay không.
switch(phepTinh) {

    case '+':
        // Tu xu ly
        break;

    case '-':
        // Tu xu ly
        break;

    case '*':
        // Tu xu ly
        break;

    case '/':
        // Kiem tra chia cho 0
        break;

    default:
        // Phep tinh khong hop le
}

  1. Khai báo biến kiểu char.
  2. Nhập ký tự bằng scanf(" %c", &bien).
  3. Dùng switch kiểm tra từng ký tự.
  4. Dùng default nếu nhập ký tự khác.

Bài 4: Số ngày trong tháng

Nhập tháng từ 1 đến 12 và xác định tháng đó có bao nhiêu ngày.
Có thể gom nhiều case có cùng kết quả: 
case 1:
case 3:
case 5:
    // Cung mot cach xu ly
    break;
Sinh viên tự xác định tháng nào có 31 ngày, 30 ngày và tháng 2.
Trung bình

Bài 5: Kiểm tra nguyên âm

Nhập một ký tự và kiểm tra ký tự đó có phải nguyên âm hay không.
Các nguyên âm gồm a, e, i, o, u. Có thể gom nhiều case liên tiếp rồi xử lý chung.

Bài 10: Menu lặp

Viết chương trình có menu lựa chọn. Sau khi thực hiện xong một chức năng, menu tiếp tục xuất hiện cho đến khi người dùng chọn 0 để thoát.
Bài này kết hợp: 
do {

    // Hien thi menu
    // Nhap lua chon

    switch(luaChon) {

        // Cac case

    }

} while(luaChon != 0);
